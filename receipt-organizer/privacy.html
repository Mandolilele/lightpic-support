小票票隐私政策

更新日期：2026-11-18。适用于iPhone App“小票票”，开发者：李川。支持邮箱：chncaun@gmail.com。

1. 本机处理与存储

App不要求注册开发者账号。你主动选择的截图、图片、PDF，以及提取文字、消费记录、分类、核对和修改痕迹保存在本机App数据容器。本机文字识别使用Apple Vision/PDFKit；开发者不设立接收这些票据的服务器，也不提供云同步。App不会自动读取微信、支付宝等其他App中的账单，不自动截图。

2. 可选在线AI

在线AI默认关闭。你选择服务商和官方接口、配置自己的API Key并明确同意后，App才会将选中票据提取出的文字、页码及当前分类通过HTTPS直接发送给该服务商，以辅助整理消费信息。可选服务包括DeepSeek、阿里云百炼、火山方舟、智谱及OpenAI；可用性取决于其支持范围。

文字可能包含姓名、商户、账号、金额、交易时间、交易编号、发票信息及其他消费事实。App不向AI发送原始图像或PDF文件，不把API Key发送给其他服务商。服务商会接收网络连接信息和验证其接口所需的凭据，可能按照其政策保存或处理请求。相关数据不因本机删除而自动从服务商删除；请核实你选择的服务商的数据保留、训练使用和删除规则。

你可随时关闭在线识别、自动补充或删除当前接口的Key；关闭后仍可使用本机识别和手工整理。启用联网需确认共享范围及可能发生的服务商费用；超时或取消仍可能计费。

3. API Key及费用记录

API Key保存在本机系统钥匙串，界面仅显示少量开头和结尾，不显示完整Key，不写入账目数据库、导出文件或普通日志。切换服务商或接口不会复制旧Key。App在本机保存模型、费率、请求用量和预算记录，以提供费用估算和限制后续请求；这不是服务商最终账单。

4. 汇率查询

仅在你请求在线汇率时向Frankfurter汇率服务发送币种代码；不发送票据、消费金额或AI Key。服务商可能处理正常网络连接信息。也可手工填写汇率。

5. 购买与免费体验

永久导出通过Apple StoreKit内购。App读取Apple签名交易来判断购买、恢复或撤销状态；开发者不处理银行卡信息。Apple根据其隐私政策处理购买。免费导出体验的批次及原有记录标识保存在独立本机钥匙串项，不包含票据图像或金额，不用于广告或跨App追踪；清除本地账目不重置已用体验。

6. 分享与权限

使用系统照片选择器或文件选择器，由你主动决定导入哪些文件。导出的Excel/PDF先写入本机，通过系统分享由你选择接收App、联系人或存储位置。只有你选择分享才交给相应目标，后续处理由目标服务的隐私规则约束。App不读取通讯录、不收集位置、不申请广告跟踪权限。

7. 广告和分析

当前版本没有商业广告、第三方广告SDK或开发者行为分析SDK，不使用票据进行广告定向，不出售用户票据或消费数据。

8. 保留、删除与备份

本机数据保留到你删除。普通删除进入回收站，清空回收站或“设置 → 清除本地数据”永久删除本机账目、凭证、识别历史、导出缓存、设置和App保存的AI Key。购买权益仍可通过Apple恢复，已用免费体验记录保留。已分享到其他位置的文件和服务商保留的请求需分别处理。App不提供开发者云备份，请在卸载或换机前自行保存材料；系统备份是否包含App数据取决于设备设置。

9. 联系与更新

如有隐私问题，请联系 chncaun@gmail.com，勿在邮件中直接发送API Key或完整敏感凭证。若未来增加新的接收方或数据用途，会更新政策并在需要时取得相应授权。
